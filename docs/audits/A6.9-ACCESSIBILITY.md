# A6.9 — Accessibility Pass (VoiceOver / web SR, Dynamic Type, touch targets, contrast)

**Task:** BUILD-PLAN A6.9. **Baselines (A6.5 tokens, `packages/tokens/tokens.json` → `a11y`):**
44px/pt minimum touch target, AA body contrast 4.5:1 (3:1 large text), focus ring
`0 0 0 3px rgba(91,103,240,0.55)`.

**Scope:** iOS SwiftUI (`apps/ios/AlgoMinutes/**`) and web React (`apps/web/src/**`).
**Android (Compose): out of scope — no app exists yet (Track B / B2). TalkBack + Compose
a11y is deferred to B2 and intentionally not scoped here.**

**Approach:** applied clear, safe, high-confidence, behaviour-preserving fixes (a11y
attributes only — no redesigns, no colour changes, no new keyboard handlers, no `console.*`).
Anything needing design/layout judgement is FLAGGED below rather than guessed.

Starting state was already strong: iOS `Typography` (`DesignSystem/Theme.swift`) scales every
text face via `UIFontMetrics`, most iOS controls were already labelled, and most web header
icon buttons + `role="button"` note rows already carried `aria-label`/keyboard support. Gaps
were narrow and targeted.

## (b) Needs design input

### Contrast (spot-check vs `#0B0B10` bg unless noted; WCAG AA = 4.5:1 normal / 3:1 large)

| Pair | Ratio | Verdict | Recommendation (design) |
|---|---|---|---|
| **`accent #5B67F0` as text on bg** | **4.34:1** | **FAILS** normal AA; passes large (3:1) | Do not use the raw accent for normal-size text/links/small labels on dark. Either reserve accent for ≥18.66px/bold-14px large text, or introduce a lighter "accent-text" token. Filled buttons are fine (white-on-accent = 4.52:1, below). |
| `accent on card #14141C` | 4.05:1 | FAILS normal; large only | Same as above — worse on elevated cards. |
| **`accentHover #454FD6` as text** | **3.13:1** | **FAILS** normal; barely large | Hover/pressed accent should not be a text colour on dark. |
| **`placeholder #5A5D6E`** | **3.02:1** | **FAILS** normal AA | Token intent is "decorative/disabled only". Confirm it is never used for meaningful text; placeholders are commonly exempt but this is a design call. |
| `white #FFFFFF on accent #5B67F0` | 4.52:1 | PASS AA (thin margin) | Filled-accent buttons OK; note the margin is slim — avoid darkening `onAccent` or lightening `accent`. |
| `body #C8CAD6` | 12.04:1 | PASS AA | — |
| `muted #8A8D9C` (on bg / card / surface) | 5.96 / 5.56 / 5.45 | PASS AA | Muted is safe as the meaningful-text floor. |
| `heading #F5F6FA` | 18.18:1 | PASS AA | — |
| status `success/warning/danger` on bg | 8.62 / 11.05 / 5.22 | PASS AA | — |

**Bottom line:** the only real failures are the **indigo accent (and accentHover) used as text**, and **placeholder** — all brand/token values, so flagged for design rather than auto-bumped.

### Dynamic Type — layouts likely to clip / not auto-fixed

- **`apps/ios/AlgoMinutes/Features/Chat/ChatView.swift:106`** — inline citation chip `chip.font = .system(size: 14, weight: .bold)` on an `AttributedString` run inside otherwise-scaling `Typography.body(15)` text. Scaling just the run needs a `UIFontMetrics`-scaled `.system` on the attributed run — low-risk but not a one-liner; secondary emphasis on already-scaling copy. Follow-up, not guessed.
- **`apps/ios/AlgoMinutes/Features/Recorder/RecordingView.swift:88`** — hero timer uses `Typography.timer(45)` (already scales), but the recording screen is a deliberately fixed layout; `RootView` clamps the app to `…accessibility3`. No change; flagged as a layout that could clip at the largest sizes if the clamp were lifted.

### Web — scalable text & touch targets needing judgement

- **Inline px `fontSize` sweep (design/eng call):** many components use inline `fontSize` in px (e.g. `App.tsx` action-card region, `ImportPanel.tsx` 16/13/14/12, `ScanPanel.tsx`). These still scale under browser page-zoom but ignore the user's default-font-size preference. Converting to rem is a broad, judgement-heavy sweep — flagged, not touched.
- **`apps/web/src/components/ChatTab.tsx:356`, `:369`** — composer Stop/Send are `w-9 h-9` (36px) round buttons; below 44px. Enlarging changes the composer's visual balance — design call.
- **`apps/web/src/App.tsx` note-detail header icon buttons** (back/cancel/save/edit/download ~1734–1789, retry ~1853, import-sheet close ~2508) — `p-2` + 20px icon ≈ 36px. Recommend `p-2`→`p-3` (=44px) or a min-size utility; repeated header-density change — flagged.
